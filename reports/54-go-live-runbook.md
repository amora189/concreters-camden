# Go-live runbook — conditional, not yet executable

This is a production handoff sequence only. It is **not** approval to deploy. The
current verdict is NO-GO and production must remain unchanged and protected by noindex.

1. Obtain and record the two D23 curing attestations; populate the matrix only from
   verifiable source or named qualified attestation.
2. Rebuild the ten service pages and 60 suburb pages under the approved provider-
   coordination model. Rewrite, do not paraphrase filler.
3. Run Gate 7 and Gate 12 until every mandatory threshold passes. Do not lower thresholds.
4. Reconcile privacy/form disclosures, schema, canonicals, breadcrumbs, menus, media,
   brand terms and the 76-page active allowlist.
5. Regenerate the derivative WXR reproducibly and verify its recorded hash. Never edit
   the seven immutable files.
6. Run the full preflight; stop on any failure.
7. Only after GO, provision private loopback-only PHP 8.3 WordPress staging with a
   rollback point before every mutation.
8. Import in documented order: Astra configuration, media, main WXR, verification,
   then any separately authorised privacy artifact; exclude `wp_css` as documented.
9. Verify database inventory, rendered pages, Elementor references, menus, forms,
   schema, robots/noindex, sitemap inventory, media, console, links and mobile QA.
10. Create a final checkpoint and page-by-page release decision. Keep production noindex,
    DNS and sitemap submission unchanged until explicit production approval.

No production command is authorised by this runbook itself.
